# I Ching Text Review — Third Pass — 2026-05-28

Scope: follow-up review of the second-pass report and keyword cleanup candidates.

This pass reviews the review. It does not propose another prose rewrite. Its purpose is to refine the keyword cleanup plan and preserve the stop condition.

## Verdict

The second-pass report is good and should become the editorial standard for this corpus.

The most important decision remains:

Do not run another broad prose polish pass.

The readings now have enough identity. Further smoothing would likely push them toward polished spiritual UX copy, which is the wrong direction for this product.

The stop condition is correct and should be treated as a product decision, not a temporary mood.

- uneven
- sometimes dry

That unevenness supports the I Ching frame.

## Adjustments To Second-Pass Suggestions

### `50` — The Cauldron

Second pass suggested:

- UK: `посудина`, `вогонь`, `варіння`
- EN: `vessel`, `fire`, `cooking`

New review is right: `варіння/cooking` is too literal.

Hexagram 50 is not just cooking. It is containment plus heat plus refinement.

Final recommendation:

- UK: `посудина`, `вогонь`, `переплавлення`
- EN: `vessel`, `fire`, `refining`

Alternative if `переплавлення` feels too metallic:

- UK: `посудина`, `вогонь`, `доведення`
- EN: `vessel`, `fire`, `refinement`

Preferred: `переплавлення / refining`.

### `15` — Modesty

Second pass suggested:

- UK: `міра`, `низьке місце`, `вага`
- EN: `measure`, `low place`, `weight`

New review is right: `низьке місце / low place` is awkward as a keyword.

Final recommendation:

- UK: `міра`, `схил`, `вага`
- EN: `measure`, `slope`, `weight`

This keeps the mountain/earth image without sounding like a phrase fragment.
