# I Ching

Product-cycle repository for **I Ching: Shape of Momentum** — a symbolic reading of the
I Ching with no predictions and no advice: an image of the present situation, its inner
dynamics, and its direction of change.

The app lives in [`i-ching/`](./i-ching/) — a SvelteKit static app shipped primarily as a
**PWA**, and wrapped with Capacitor for iOS / Android. See its
[README](./i-ching/README.md) for philosophy, architecture, development, and roadmap.

The repository root holds product-cycle material around the app — App Store assets and
copy in [`AppStore/`](./AppStore/), design notes, editorial reviews.

```sh
cd i-ching
yarn install
yarn dev
```
